## ■ 最重要原則: 動的完成度判定アルゴリズム (Address Extraction Rule v3)

```
┌─────────────────────────────────────────────────────────────┐
│ 住所抽出の判定基準は、固定の階層番号 (第1階層/第2階層) ではなく │
│ 「取得した住所文字列の完成度（配布単位としての完了度）」で動的判断する。 │
└─────────────────────────────────────────────────────────────┘
```

---

## ■ 判定フローチャート (Dynamic Completeness Decision)

```
                         【自治体名 取得】
                                │
                                ▼
                       【第 1 住所階層 取得】
                                │
                                ▼
                 【その時点で「丁目」を含むか？】
                                │
       ┌────────────────────────┴────────────────────────┐
       │ YES                                             │ NO
       ▼                                                 ▼
【そこで確定終了】                               【第 2 住所階層 取得】
(例: 東員町 └ 1丁目)                             (例: 桑名市 └ 江場 └ 1丁目)
➔ 「東員町1丁目」                                ➔ 「桑名市江場1丁目」
                                                 (例: 桑名市 └ 長島町 └ 千倉)
                                                 ➔ 「桑名市長島町千倉」
                                                         │
                                                         ▼
                                                 【そこで確定終了】
```

## ■ 正確な判定テーブル

| 住所構造パターン | 入力例 | 抽出結果 | 判定理由 | 終了条件 |
| :--- | :--- | :--- | :--- | :--- |
| **直下丁目パターン** | 東員町 ＋ 1丁目 | **東員町1丁目** | 1階層目で「丁目」を含むため完成 | **1階層取得で即時終了 ✅** |
| **町名＋丁目パターン** | 桑名市 ＋ 江場 ＋ 1丁目 | **桑名市江場1丁目** | 1階層目「江場」が粗いため第2階層「1丁目」を取得 | **2階層取得で確定終了 ✅** |
| **町名＋字/地区パターン** | 桑名市 ＋ 長島町 ＋ 千倉 | **桑名市長島町千倉** | 1階層目「長島町」が粗いため第2階層「千倉」を取得 | **2階層取得で確定終了 ✅** |

## ■ 誤りやすかった従来ロジックとの決定的な違い

- ❌ **誤った従来考え**: 「第1階層＝町名」「第2階層＝丁目」と機械的に決め打ちする。
- ✅ **正しい Rule v3**: **「第1取得結果が完成住所（丁目含む）ならその場で終了、未完成なら次階層を取得して終了」**

このルールにより、全国 289 選挙区の全自治体において：
1. 「○○町1丁目」の自治体
2. 「○○町○○」の地域
3. 大字・字が存在する地域

を**同一コード・同一決定論的ルール**で 100% 完全自動処理できます。
